1. What aspect of machine learning did you find most technically challenging in completing this term project?

The initial (first iteration) creation of the experiment / notebook.  Figuring out how to write the methods to generate the primes and 
factorization methods was the easier portion, but generating the code to do the training and evaluation was difficult.  It was even more 
difficult to incorporate more factorization methods after I had already set up the initial experiment.  Luckily, I had good baseline code 
to start with and was able to adapt.

2. What aspect of machine learning do you think you learned the most about over the course of the project?

I think the aspect of machine learning I learned the most about over the course of this project was reinforcement learning and how reward 
design influences an agent's behavior. By developing a PPO agent to select among five integer factorization methods, I learned how important 
it is to define the environment, observation space, action space, and reward function carefully. The agent needed to learn when to use trial 
division, wheel factorization, Fermat's factorization, Pollard's rho, or Pollard's p−1 based on the characteristics of the input.

3. What is your top priority for future work, if you were to continue this project as a research project or in independent study?

I would expand the integer factorization methods to include more; I can potentially double the sample size by adding Elliptic Curve 
Factorization, Quadratic Sieve, General Number Field Sieve, Special Number Field Sieve, and/or Dixon's algorithm, to name a few.
